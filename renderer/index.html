    Quick add

    Add words from an app or page title. Ignore is for whole apps. On Windows, sydtrack does not read browser addresses, so site: rules cannot match; use title words instead.

    Type a keyword to see which list it is in.

    Productive

    One keyword per line: editors, docs, work sites.

    Unproductive

    One keyword per line: social, video, rabbit holes. Unproductive wins when both lists match.

    Ignore

    Shown in tracking status but not logged (no time, no streak). One process name per line.

    Other overrides

    Title words kept neutral even when a broader productive or unproductive rule matches. These belong to the active Focus profile.

    Browser keywords

    Exact title words used after profile rules miss. Unmatched browser pages stay Other. One keyword per line.

    What sydtrack stores

    sydtrack checks the app you're using and its window title. On Windows, it does not read browser addresses. Pause tracking to stop these checks.

    Daily history keeps app names, categories, time, and the word or rule that matched. The active title appears live, but sydtrack does not save a title-by-title log. Sessions and optional session labels, Focus profiles, settings, and error logs also stay on this computer.

    Detailed history and the day timeline stay for 90 days. After that, daily, hourly, and app totals remain for lifetime stats. The exact sequence and matched words expire.

    No screenshots, keystrokes, background-window history, or automatic activity uploads. Exports are files you choose to save and can contain private activity details.

    Backups are private

    They can contain app names, matched words, session labels, and activity history.

    Import merges activity with your existing data. Importing the same backup twice adds its activity twice.

    Error logs stay on this computer and are not included in backups.
