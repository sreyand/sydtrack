Quick add

Add a keyword like youtube or github from the page title. Browser tracking uses the foreground title, regardless of browser engine. Ignore is for whole apps. Existing site: rules apply only when a website address is available.

Type a keyword to see which list it is in.

Productive

One keyword per line: editors, docs, work sites.

Unproductive

One keyword per line: social, video, rabbit holes. Unproductive wins when both lists match.

Ignore

Shown in tracking status but not logged (no time, no streak). One process name per line.

Browser keywords

Exact title tokens used after Focus Tags miss. Unproductive wins. One keyword per line. Stored only on this computer.

Data

Privacy warning

Exports include app names, window titles, and time history. Treat a .sydtrack file like a personal diary. There is no cloud sync — only you choose where to save or open a backup on this machine (or copy the file yourself between PCs).

Includes activity, sessions, settings, Focus Tags, and app identities. Import adds activity totals; matching session IDs are kept once. A running session is exported as a stopped checkpoint and never auto-started on import.

Local error logs are kept in the logs folder inside the Data location above (two files, approximately 256 KB each). Logs are never uploaded or included in backups.
