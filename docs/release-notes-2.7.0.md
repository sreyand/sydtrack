# sydtrack v2.7.0

- **Next-day resume:** optionally end new untimed pauses at local midnight, or on wake or launch. Off by default; timed pauses are unchanged.
- **UI glisten:** optional sheen on cards and controls. The quick hover sweep requires UI motion and respects reduced motion.
- **Sidebar motion:** a reversible slide and turning caret when UI motion is enabled.
- **Analytics:** clearer hour guides in light themes and locale-aware times for Peak Productivity and Roundup’s Peak Hour.

Windows 10/11 x64. Quit sydtrack from the tray before upgrading. Setup and portable builds are unsigned. See the [validation report](release-validation-2.7.0.md).
