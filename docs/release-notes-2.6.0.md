# sydtrack v2.6.0

## Added

- **Daily theme rotation:** choose Night (dark), Day (light), or ALL. Picking a theme manually disables rotation.
- **UI motion:** optional button feedback, uninterrupted tab transitions, quick menu entrances, and animated pie charts. Off by default; respects reduced motion.
- **Show/hide shortcut:** choose Ctrl+Alt+S, Ctrl+Shift+S, or Alt+S in Tracking settings.

## Improved

- Live charts and focusscore grids update without resetting focus or hover.
- Returning from Day Analytics no longer leaves the last-opened day highlighted.
- Consistent Settings dropdowns and sidebar alignment.
- Lighter page transitions, stable menu positioning, and no delayed second FocusBoost press.
- Week comparisons use “Up/Down …% from last week.” This remains a difference in percentage points, not a relative increase.

## Upgrade

Windows 10/11 x64. Quit sydtrack from the tray before upgrading. Existing data and settings are retained; classification and Focus Share are unchanged.

Setup and portable builds are unsigned. Manual acceptance and publication are pending. See the [validation report](release-validation-2.6.0.md).
