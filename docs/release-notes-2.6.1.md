# sydtrack v2.6.1

## Fixes

- Removed Analytics tab flicker with UI motion on or off.
- Week and Month views update in place instead of blanking and rebuilding.
- Stabilized tab widths, headers, scrollbars, and loading indicators.
- Interrupted tab animations continue smoothly.
- Timelines and app lists stay visible while loading; activity updates preserve keyboard focus and ignore outdated responses.

## Upgrade

Windows 10/11 x64. Quit sydtrack from the tray before upgrading. Existing history and settings are retained; classification, Focus Share, and storage formats are unchanged. UI motion remains optional and respects reduced motion.

Setup and portable builds are unsigned. Manual acceptance and publication are pending. See the [validation report](release-validation-2.6.1.md).
